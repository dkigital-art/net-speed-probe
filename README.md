# speedcheck — замер скорости интернета

Консольный скрипт на Python: последовательно скачивает файл по HTTP GET и считает среднюю скорость канала.

## Требования

- Python 3.10+
- Внешних зависимостей нет (только стандартная библиотека: `urllib.request`, `time`, `argparse`, `unittest`)

## Запуск

```bash
# базовый замер (10 запросов, таймаут 15 с, cache-busting включён)
python speedcheck.py https://proof.ovh.net/files/1Mb.dat

# свои параметры
python speedcheck.py https://proof.ovh.net/files/10Mb.dat --requests 5 --timeout 30

# отключить cache-busting
python speedcheck.py https://proof.ovh.net/files/1Mb.dat --cache

# тесты
python -m unittest
```

При сетевой ошибке или HTTP-статусе ≠ 200 скрипт печатает понятное сообщение в stderr и завершается с кодом `1`.

## Единицы измерения

Выводятся **обе** величины — они отвечают на разные вопросы:

| Единица | Как считается | Зачем |
|---------|---------------|--------|
| **Мбит/с (Mbps)** | `(bytes × 8) / 1_000_000 / sec` (десятичная приставка SI) | Так заявляют скорость провайдеры |
| **МБ/с (MB/s)** | `bytes / (1024 × 1024) / sec` (двоичная MiB) | Реальный темп скачивания файлов |

Соотношение примерно: `1 МБ/с ≈ 8.39 Мбит/с` (из‑за разницы binary MB и decimal Mbit).

Объём в отчёте тоже в binary MB: `1 MB = 1024 × 1024` байт.

## Cache-busting

По умолчанию (`--no-cache`) к URL добавляется уникальный query-параметр `_=<timestamp>`, а в запрос — заголовки `Cache-Control: no-cache` и `Pragma: no-cache`. Иначе CDN или прокси могут отдать файл из кэша и завысить «скорость». Отключить: `--cache`.
