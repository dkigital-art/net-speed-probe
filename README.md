# speedcheck — замер скорости интернета

Консольный скрипт на Python: принимает URL, делает **10 последовательных HTTP GET**, дожидается полного ответа каждого, считает среднее время, суммарный объём скачанных данных и скорость загрузки.

## Требования

- Python 3.10+
- Внешних зависимостей нет (только стандартная библиотека)

## Запуск

```bash
# базовый замер (10 запросов, таймаут 15 с)
python speedcheck.py https://proof.ovh.net/files/1Mb.dat

# свои параметры
python speedcheck.py https://proof.ovh.net/files/10Mb.dat --requests 5 --timeout 30

# тесты
python -m unittest
```

Запросов:         10

При сетевой ошибке или HTTP ≠ 200 скрипт пишет сообщение в stderr и завершается с кодом `1`.

## Единицы измерения скорости

В консоль выводятся **обе** величины:

| Единица | Как считается | Зачем |
|---------|---------------|--------|
| **Мбит/с (Mbps)** | `(bytes × 8) / 1_000_000 / sec` (десятичная приставка) | так обычно заявляют скорость провайдеры |
| **МБ/с (MB/s)** | `bytes / (1024 × 1024) / sec` (двоичная) | реальный темп скачивания файлов |

Объём в отчёте тоже в binary MB: `1 MB = 1024 × 1024` байт.  
Ориентир: `1 МБ/с ≈ 8.39 Мбит/с` (из‑за разницы binary MB и decimal Mbit).

## Cache-busting

К каждому запросу добавляется уникальный query-параметр `_=<timestamp>` и заголовки `Cache-Control: no-cache` / `Pragma: no-cache`. Иначе CDN или прокси могут отдать файл из кэша и завысить результат.
